# PSR-3114 - Product Safety Risk Banding Standard (LaTeX source mirror)

This repository is a plain text mirror of the public LaTeX source of the
PSR-3114 Product Safety Risk Banding Standard (Rev. 3), kept for citation
purposes.

It contains no runnable code. The normative banding appendix
(`banding-matrix.tex`) was distributed separately to programme participants and
is not included in this mirror.
